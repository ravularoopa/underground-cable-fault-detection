Underground Cable Fault Detection Project Plan

1. Project Overview

This project aims to develop a system that can estimate the location of faults in underground electrical cables.

2. Problem

When an underground cable develops a fault, finding its location can take time. This project explores ways to identify the fault location more quickly.

3. Proposed Approach

We will study a suitable fault detection technique and develop a simulation or prototype to estimate the location of a cable fault.

4. Tools to Explore

- MATLAB/Simulink
- Electrical circuit simulation
- Arduino and sensors (if required for the selected prototype)

5. Expected Outcome

A working simulation or prototype that demonstrates a suitable method for detecting and estimating underground cable fault locations.

6. Current Status

Project planning and research.

7. Future Improvements

- Display the estimated fault distance.
- Add fault alerts.
- Explore real-time monitoring.
