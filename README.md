Underground Cable Fault Detection System

1. Introduction

Underground cables are widely used in electrical power distribution systems. When a fault occurs, identifying its exact location can be difficult and time-consuming.

This project aims to develop a system that helps identify the location of faults in underground electrical cables.

2. Problem Statement

Finding faults in underground cables manually can require considerable time and effort. A system that helps locate faults can reduce troubleshooting time.

3. Objectives

- To detect faults in underground cables.
- To estimate the location of a fault.
- To reduce fault identification time.
- To improve the reliability of electrical power distribution.

4. Proposed Method

The proposed system may use sensors or electrical measurement techniques to detect abnormal conditions and estimate the fault location.

The final method will depend on the hardware, software, and fault detection technique selected.

5. Applications

- Underground power distribution networks
- Electrical maintenance
- Industrial power systems
- Power system reliability improvement

6. Future Scope

The system can be improved by adding real-time monitoring, automatic fault alerts, and a digital display of the estimated fault location.

7. Project Status

Currently in the planning and development state.
